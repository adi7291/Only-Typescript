# Never Data types
-------------------
=> never represent value that never occur. It is commonly used for function that always throw an error or never terminate.
=> never -> function that never successfully finishes.

# Void data types
-----------------
=> A void function finished but doesn't return a useful value.

# Differences:
--------------
never => never finishes successfully.
void  finishes successfully.
=>Bot return nothing.
=> never user to throw Error function and  infinity loop
