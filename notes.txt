# Any type in typescript
============================

When we define a variable with any type it loses its type we can assign its value of any type i.e
string boolean number object  etc...

avoid using "any" in typescript as much as you can.
it removes typescript safety

# UNKNOWN
=========
They variable type is not known but before using it find the type and use it.
It keeps typescript safety.

let value :unknown = 'Hello';
console.log(value.upperCase())//
